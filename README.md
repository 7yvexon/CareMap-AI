# CareMap AI — 전국 통합돌봄 자원 분포 시제품

지역과 필요한 도움을 선택해 전국 통합돌봄 프로그램 후보를 찾고, 행정동·시군구별 인구와 자원 현황을 살펴보는 공개자료 기반 시제품입니다. 주민과 현장 담당자의 서비스 탐색을 돕는 것을 목표로 합니다.

## 실행

Node.js 18 이상에서 저장소 루트에서 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:8765/ 를 엽니다. 시작 전에 `scripts/build-data.mjs`가 원본 CSV를 읽어 화면용 자료와 시군구 요약 CSV를 다시 생성합니다. 서버는 서비스 원본 CSV와 압축 행정동 경계를 읽어 검색 API와 선택 지역별 경계 API를 제공합니다. 배경지도에는 인터넷 연결이 필요합니다.

## 현재 범위

- 전국 16개 시도, 256개 시군구 단위, 3,620개 행정동 자료
- 행정동별 65세 이상 주민등록인구와 65세 이상 1인 세대
- 시군구별 통합돌봄 서비스 자원 목록 90,081행을 6개 실제 대분류로 집계
- 보건복지부 복지시설유형별 입소정원수·시설생활자수 월별 자료(2025년 12월, 35개 유형 중 노인 관련 9개 유형 표시)
- 시도 지도, 시군구 비교, 행정동 고령인구 참고 순위
- 전국 시도 → 시군구 → 읍면동 단계 선택, 지도 경계 클릭 및 선택 행정구역 확대
- 전국 또는 선택 지역에서 필요한 도움을 입력해 프로그램명·분류·기관명에 일치하는 서비스 후보 검색(도시락·병원 동행·복약관리 예시 제공)
- 자료 기준일, 원자료 링크, 주소·연락처 공란 수를 화면에 표시

## AI 적용 범위와 검증 계획

- 현재 웹 데모의 검색은 키워드·서비스 분류 일치도를 계산하는 투명한 기준선입니다. 학습된 모델이나 외부 생성형 AI API는 연결되어 있지 않습니다.
- 제안하는 AI 흐름은 자연어 요청에서 도움 유형을 추출하고, 서비스 분류에 연결한 뒤 원자료에서 후보를 검색(RAG)하고, 일치한 원자료 항목을 근거로 제시하는 방식입니다.
- 결과는 상담·탐색 후보이며 이용 자격이나 실제 운영 여부를 판정하지 않습니다. 담당자 또는 이용자가 기관에 확인해야 합니다.
- 검증은 현장 담당자가 작성한 질의 사례를 사용해 상위 3개 후보의 적합도, 원자료 근거 일치율, 수작업 대비 탐색 시간, 연락처 최신성을 측정하는 계획입니다. 아직 검증 결과는 없습니다.
- 이름·주민등록번호 등 개인식별정보를 입력하지 마세요. 검색 요청은 저장하거나 기록하지 않습니다.

## 데이터 해석과 한계

- 65세 이상 인구와 고령 1인 세대는 지역 상황을 보는 참고 지표입니다. 실제 서비스 필요, 자격, 미충족 수요를 나타내지 않습니다.
- 건강보험공단 목록은 서비스 프로그램·자원 행입니다. 한 기관이 여러 행에 나타날 수 있으므로 행 수를 고유 기관 수나 정원으로 해석하지 않습니다.
- 통합돌봄 목록에는 장기요양, 보건의료, 건강관리, 일상생활, 주거복지 등 여러 유형이 포함됩니다. 모든 행이 노인 전용 서비스는 아닙니다.
- 원자료에서 기관 주소 505행(0.56%), 연락처 3,559행(3.95%)이 비어 있습니다. 세종특별자치시의 347행은 시군구 없이 시도 단위로 등록되어 있습니다.
- 건강보험공단 CSV에는 euc-kr로 복원되지 않는 문자 6개가 있어 생성 데이터에서는 대체문자로 표시합니다. 원본 파일은 그대로 보존합니다.
- 공단 설명은 소분류 34종을 명시하지만, 내려받은 CSV에서 실제 행이 관측된 소분류는 28종입니다. 나머지 6종이 해당 스냅샷에 없는 것인지 자료 누락인지는 확인이 필요합니다.
- 인구 자료는 2026-10-31, 서비스 자원 목록은 2026-06-30 기준입니다. 목록은 일회성 스냅샷이므로 기준일을 분리해 표시합니다.
- 서비스 자원 목록에는 기관별 정원·현원·대기 인원·이용량이 없습니다. 장기요양기관 API에서 제공되는 일부 기관의 수용 정보는 이 버전에 결합하지 않았습니다.
- 별도 보건복지부 통계는 시설유형별 지역 집계이며, 읍면동별·기관별 현황이나 공실 수가 아닙니다. 2026년 행정구역과 대조해 212개 시군구는 지역명이 직접 일치하고, 39개는 상위 도시 전체, 5개는 시도 집계를 표시합니다. 상위 집계값을 하위 시군구에 나눠 배분하지 않습니다.
- 보건복지부 원자료의 입소정원수·시설생활자수는 시설유형별로 의미가 다를 수 있어 화면에서 서로 다른 유형의 합계나 정원-생활자 차이를 이용 가능 인원으로 해석하지 않도록 안내합니다.
- 서비스 주소를 개별 좌표로 바꾸지 않았습니다. 지도에는 기관 핀이나 이동시간·서비스 커버리지를 표시하지 않습니다.
- 전국 시도 배경 경계는 geoBoundaries/Natural Earth 2021 자료이며, 선택 시군구·읍면동은 통계청 SGIS 기반 2026-10-01 경계를 표시합니다. 인구자료의 3,620개 행정동 가운데 3,558개 코드가 세부 경계와 일치합니다. 출장소 등 62개 단위는 개별 경계가 없어 상위 시군구 범위로 안내합니다.
- 현재 버전은 예측 모델을 학습한 AI가 아니라 공개자료 기반의 집계·비교 시제품입니다.

## 원본 및 생성 파일

- 원본 CSV와 행정경계 파일: `data/source/` (읍면동 경계 GeoJSON은 gzip으로 무손실 압축)
- 전국 행정동 자료, 시군구·시도 집계, 지도 경계: `data/national_data.js` (생성)
- 시군구 집계 CSV: `data/national_district_summary.csv` (생성)
- 기존 울산 시범 자료는 비교 참고용으로 저장소에 남아 있으며 현재 대시보드에서 사용하지 않습니다.

공공데이터포털 CSV 원본은 euc-kr 계열 인코딩으로 내려받으며, 생성 스크립트가 `euc-kr`로 읽습니다. 원본을 갱신할 때에는 파일명과 기준일을 함께 갱신하고, 인구·1인 세대의 행정기관 코드 집합이 일치하는지 확인해야 합니다.
