# 의미검색 평가 계획 초안

이 문서는 CareMap의 선택형 의미검색을 기존 규칙 검색과 비교하기 위한 평가 초안이다. 아래 질의는 실제 이용자 기록이 아닌 합성 예시이며, 사회복지 현장 담당자의 검토와 표본 평가 전에는 정확도나 현장 효과로 인용하지 않는다.

## 평가 대상

- **기준선:** 현재 규칙 기반 유형 추출과 키워드 검색
- **의미검색:** 브라우저의 `multilingual-e5-small` 임베딩으로 28개 사회서비스 중분류 설명을 비교해 상위 3개 유사 유형 후보를 보여준다. 사용자가 고른 유형만 의미검색 `intent`로 추가하며 기존 규칙 추론과 입력어 검색도 함께 원자료 후보를 찾는다.
- **평가 단위:** 이용자 질의 1개와 유형 상위 3개, 서비스 후보 상위 8개
- **금지할 결론:** 인구·자료 관측 상태만으로 실제 미충족 수요, 복지 공백, 지원 자격을 판정하지 않는다.

## 합성 질의 초안

| 질의 | 기대 유형 | 구분 |
|---|---|---|
| 혼자 지내는데 식사를 챙기기 어려워 반찬을 받고 싶어요 | 식사지원 | 일상 표현 |
| 병원에 갈 때 같이 가 줄 사람이 필요해요 | 이동지원 | 동행 표현 |

| 집에 문턱이 높고 화장실에서 미끄러질까 걱정돼요 | 주거공간개선 | 주거 안전 |
| 걷기 연습이나 집에서 받을 수 있는 재활이 궁금해요 | 방문재활 | 재활 |

| 외출할 때 이동 차량이나 도움을 받을 수 있을까요 | 이동지원 | 이동 지원 |

| 청소, 식사, 외출 등 여러 생활 지원을 한 번에 알아보고 싶어요 | 건강-돌봄 통합지원 | 복합 필요 |
| 농촌에서 돌봄과 주민 활동을 함께 할 수 있는 곳이 있나요 | 농업-돌봄연계 | 지역 특화 |
| 밤에도 안전 확인이나 긴급 연락을 받을 수 있을까요 | 상시돌봄지원 | 안전 지원 |
| 어르신 서비스 알려줘 | 검토 필요 | 모호한 질의 |
| 복지랑 상관없는 여행 코스를 추천해 줘 | 사회서비스 유형 없음 | 범위 밖 질의 |

## 측정 방법

1. 현장 담당자 2명이 각 질의의 적절한 서비스 중분류를 독립적으로 지정하고, 의견이 다르면 합의 라벨을 기록한다.
2. 규칙 검색과 임베딩 검색 각각의 **유형 Top-1 적합도**와 **Recall@3**를 계산한다. 사용자가 선택한 유형이 기준 라벨과 맞는지도 별도 집계한다. 현재 임베딩은 모든 질의에 유사 후보를 표시하므로, 모호·범위 밖 질의에서 `무분류/확인 필요`를 택할 수 있는지와 잘못된 유형을 선택하는 비율도 평가한다.
3. 서비스 후보 상위 8건마다 원자료 프로그램명·대분류·중분류가 표시된 근거와 실제 질의가 일치하는지 두 사람이 확인해 **근거 일치율**을 계산한다.
4. 같은 지역·질의 조건으로 기준선과 의미검색의 후보 탐색 시간을 재고, 모델 첫 로드 시간과 캐시 후 응답 시간은 기기·브라우저별로 분리 기록한다.
5. 질의는 이름·주민등록번호·전화번호·실제 상담 기록을 포함하지 않는다. 실제 이용자 질의를 수집하려면 별도 동의·보안 검토가 필요하다.

## 현재 상태와 공개 원칙

- 구현된 모델은 일반 다국어 임베딩 모델이며 사회복지 질의로 미세조정하지 않았다.
- 위 표는 합성 질의 초안일 뿐, 라벨 타당성·모델 정확도·현장 사용성은 검증되지 않았다. 후보 유형은 이용자 확인을 거치도록 했지만, 임베딩 자체의 범위 밖 질의 판별은 아직 구현·검증되지 않았다.
- 결과를 발표할 때는 질의 수, 검토자 수, 모델·기준선별 Top-1/Recall@3, 근거 일치율, 첫 로드·반복 응답 시간을 함께 공개한다. 숫자가 나오기 전에는 성능 향상 주장을 하지 않는다.
- 모델 유사도는 확률이나 서비스 이용 가능성 지표가 아니며, 최종 연락·이용 여부는 이용자와 기관이 확인한다.
