# CareMap 의미검색 현장 검토 기록지

이 기록지는 합성 질의로 서비스 유형 후보와 검색 결과의 적합성을 검토하기 위한 빈 양식이다. 실제 이용자의 상담 문장·이름·연락처 등 개인정보를 입력하거나 기록하지 않는다. 검토자 2명은 먼저 서로의 답과 모델 결과를 보지 않고 1차 분류를 작성한다.

검토자는 이 파일의 질의·공식 데이터 설명만 보고 분류한다. `docs/ai-search-evaluation.md`의 기대 유형 열이나 다른 검토자의 응답은 1차 분류가 끝날 때까지 열람하지 않는다.

## 2차: 결과와 원자료 근거 검토

1차 분류를 저장한 뒤 CareMap에서 같은 질의와 같은 범위로 검색한다. 의미검색을 켜고 첫 제출에서 나온 상위 3개 후보를 기록한다. 각 후보의 유사도 점수는 확률이나 적합도 확정값으로 보지 않는다.
다음으로 의미검색을 끄고 같은 질의를 검색해 규칙·키워드 기준 결과를 기록한다. 상위 후보 카드의 프로그램명·유형·제공기관 등 원자료 근거를 읽고, 실제로 질문에 도움이 되는 탐색 후보인지 평가한다.

## 결과 요약

| 지표 | 결과 |
| --- | --- |
| 독립 검토자 수 |  |
| 1차 분류에서 일치한 문항 수 / 20 |  |
| 합의 라벨 수 / 평가 가능한 문항 수 |  |
| 의미검색 Top-1 일치 수 / 평가 가능한 문항 수 |  |
| 의미검색 Recall@3 일치 수 / 평가 가능한 문항 수 |  |
| 규칙 검색 유형·후보의 근거 적합도 요약 |  |
| 범위 밖·모호 질문에서 오해를 부르는 유형을 제시한 사례 |  |
| 모델 첫 로드 / 반복 실행 시간과 측정 기기 |  |

20개 합성 질의는 소규모 예비 검토다. 검토자 불일치와 평가 제외 사유를 함께 기록하고, 결과만으로 일반 이용자의 정확도·현장 효과·AI의 우수성을 주장하지 않는다. 제출 자료에는 검토자 수, 질의 수, 기기, 기준선, 점수 정의와 표본 한계를 함께 적는다.
