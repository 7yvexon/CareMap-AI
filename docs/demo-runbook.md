# CareMap AI 로컬 시연 runbook

Windows PowerShell에서 저장소 루트를 열고 진행합니다. 이 시제품은 Node.js 18 이상과 로컬 원본 데이터 파일을 필요로 합니다. 처음 패키지를 설치할 때는 npm 레지스트리에 연결되어야 합니다.

## 실행

```powershell
npm install
npm start
```

`npm start`는 먼저 `scripts/build-data.mjs`를 실행해 전국 화면 자료를 생성하고, 이어서 로컬 서버를 시작합니다. 터미널에서 아래 순서의 메시지를 확인한 뒤 브라우저를 엽니다.

```text
Preparing SQLite service catalog...
Service catalog loaded: ... rows in ... ms
CareMap AI: http://127.0.0.1:8765 (... resources, ... dong boundaries indexed)
```

SQLite 캐시가 없거나 원본 CSV와 달라 재생성이 필요하면 두 번째 메시지에 `rebuilt`라고 표시됩니다. 서버가 URL을 출력하기 전에 브라우저를 열면 아직 응답하지 않을 수 있으니 URL 로그가 나온 뒤 `http://127.0.0.1:8765/`에 접속합니다.

### 기본 포트가 사용 중일 때

터미널에 `port 8765 is already in use`가 나오면 해당 CareMap 서버가 이미 실행 중인지 확인합니다. 다른 프로그램이 사용 중이거나 실행 중인 서버를 쓸 수 없다면 다른 포트를 지정합니다.

```powershell
$env:PORT = '8766'
npm start
```

서버 로그에 표시된 주소로 접속합니다. 이 PowerShell 창에서 환경 변수를 지우려면 서버를 `Ctrl+C`로 종료한 뒤 다음을 실행합니다.

```powershell
Remove-Item Env:PORT -ErrorAction SilentlyContinue
```

## 브라우저에서 시연

1. 헤더의 `자료 준비됨` 상태와 자료 기준일·지역 경계 개수를 확인합니다. `자료 상태 확인 필요`나 `시군구 경계 확인 필요`가 나오면 터미널 로그와 상태 설명을 먼저 확인합니다. 상태 API 응답이 5초 안에 오지 않으면 `서버 상태 응답 지연`으로 표시됩니다.
2. 지역 선택에서 전국 → 시도 → 시군구 → 읍면동을 차례로 선택합니다. 각 단계에서 통계와 선택 범위가 바뀌는지, 지도가 해당 지역으로 확대되는지 확인합니다. 읍면동 서비스 자원 검색은 제공되지 않으므로 검색 결과는 상위 행정지역 범위로 표시됩니다. 세종의 서비스 기록 347행은 시도 단위라 시군구별로 배정되지 않습니다.
3. `아동 돌봄 · 인구 참고` 모드로 전환합니다. 먼저 0~17세 인구 비율 지도를 보고, 이어 `지역아동센터 기록 관측` 지도와 전국·선택 지역의 관측 상태를 살펴봅니다. 2026-11-14 수집본에서 256개 시군구 중 146곳은 기록이 관측되고 110곳은 미관측입니다. 미관측은 수집본에서 기록을 찾지 못했다는 뜻이지 센터가 없다는 판정이 아닙니다. 읍면동을 선택하면 상위 시군구 상태가 표시됩니다.
4. 어르신 돌봄 모드로 돌아와 의미 기반 AI 추천을 끈 상태에서 `도시락` 또는 `병원 동행`을 검색해 규칙·키워드 기준 후보를 확인합니다. 시도나 시군구를 선택한 뒤 다시 검색해 범위가 적용되는지도 확인합니다.
5. 선택적으로 의미 기반 AI 추천을 켭니다. 첫 검색에서는 카탈로그의 대·중분류 조합 상위 3개 후보를 보여주며, 사용자가 조합을 고르고 다시 검색해야 그 pair가 원자료 후보 근거에 추가됩니다. 이 경로가 정상인지 확인하려면 PowerShell에서 `Invoke-RestMethod http://127.0.0.1:8765/api/service-categories`를 실행해 `{ categories: [{ major, minor }, ...] }` 응답을 확인합니다. 코드에는 모델 오류·90초 초과 시 규칙 기반 검색으로 전환하는 경로가 있지만, 실제 오류·시간 초과 상황은 아직 재현하지 않았습니다.
6. 결과가 없으면 화면 안내에 따라 검색어를 바꾸거나 전국 범위로 넓혀 봅니다. 결과는 공개자료에 기록된 프로그램 후보이며 현재 운영 여부, 이용 가능성, 자격을 보장하지 않습니다.

## 인터넷이 없거나 요청이 실패할 때

- 배경 타일은 OpenStreetMap에서 받아오므로 배경지도에는 인터넷 연결이 필요합니다. 타일을 불러오지 못해도 행정구역 경계는 계속 표시되며, 화면의 타일 재시도 버튼을 사용할 수 있습니다.
- 선택 지역의 세부 경계 요청이 실패하면 시도 경계를 표시하고 `행정경계 다시 시도` 버튼을 보여줍니다.
- 의미검색을 처음 사용할 때는 Transformers.js 모듈과 약 140MB의 모델 파일을 외부 서버에서 받아야 합니다. 코드에는 모델 오류 또는 90초 초과 시 규칙 기반 검색으로 전환하는 경로가 있으나, 실패 상황은 아직 브라우저에서 검증하지 않았습니다. 모델 파일 없이 AI 추천을 처음 사용하는 오프라인 시연도 확인하지 않았습니다.
- 서비스 검색 API가 15초 안에 응답하지 않으면 시간 초과 안내가 표시됩니다. 같은 조건으로 다시 검색하거나 터미널에서 서버 상태를 확인합니다.
- 지역별 서비스 유형 집계가 15초 안에 끝나지 않으면 미리 생성된 지역 요약으로 전환됩니다.
- 위 시간 초과·오류 안내와 fallback은 코드에 구현된 동작을 정리한 것입니다. 실제 장애를 재현한 검증은 완료되지 않았습니다.

## 검증 상태

### 개발 환경에서 실제 실행으로 확인한 항목 (2026-11-15)

- Node v24.22.1에서 `node scripts/build-data.mjs`를 실행해 전국 3,620개 읍면동·256개 시군구·16개 시도 경계 자료와 서비스 자원 90,081행을 생성했습니다. 기본 포트 8765는 이미 사용 중이어서 임시 포트 8766에서 `node server.mjs`를 실행했습니다. `/api/health`는 `ready: true`, 서비스 90,081행, 경계 3,559개, 시도 16/16, 시군구 256/256을 반환했습니다.
- Chrome에서 `http://127.0.0.1:8766`을 열어 `자료 준비됨`, OpenStreetMap 타일과 전국 행정경계를 확인했습니다. 서울특별시 → 강남구 → 대치2동 선택과 해당 동 강조 표시도 확인했습니다.
- 온라인 상태에서 의미검색을 처음 사용해 모델 내려받기와 준비가 완료되는 것을 확인했습니다. 합성 질의 `병원 동행`의 상위 제안은 보건의료 › 방문진료 0.849, 보건의료 › 방문재활 0.846, 일상생활돌봄 › 이동지원 0.846이었습니다. 이동지원을 선택하자 전국 서비스 후보 8건이 나왔고, 카드에 선택한 대·중분류 쌍과 입력어 근거가 표시됐습니다. 이는 한 질의의 기능 확인이며 모델 정확도 평가가 아닙니다.
- 기준 검색에서 `병원`을 조회했을 때 입력어 일치 후보 8건이 별도 그룹에 표시됐고, 선택한 지역·대분류 범위는 적용되며 규칙 분류·선택 쌍 근거는 없는 후보라는 설명을 확인했습니다.

### 실행하지 않은 항목과 남은 제한

- 이 실행 환경에서 `npm` 명령을 찾지 못해 `npm start`를 직접 실행하지 않았습니다. 데이터 생성과 `node server.mjs` 구동은 확인했지만, 이것만으로 `npm start` 또는 발표 PC 동작을 확인한 것은 아닙니다.
- 자동화 테스트 스위트, 모델 캐시 후 재실행, 검색·요약 API 시간 초과와 fallback, 90초 의미검색 fallback, 오프라인 지도·검색, 좁은 화면·스크린리더, 발표 장비는 확인하지 않았습니다.
- 모델 유사도는 확률이나 적합도 점수가 아니며, 위 한 질의의 순위는 사회복지 현장 평가가 아닙니다. 발표 PC에서 첫 다운로드와 실제 시연 순서를 별도로 확인해야 합니다.

### 발표자가 사전에 직접 확인할 항목

- [ ] 발표 PC에서 `npm install`과 `npm start`가 끝까지 실행되고 URL 로그가 나오는지
- [ ] 브라우저에서 `자료 준비됨`이 표시되고 전국 → 시도 → 시군구 → 읍면동 선택이 되는지
- [ ] 어르신 모드와 아동 모드 사이에서 전환되고, 아동 인구 지도와 센터 기록 관측 지도가 서로 다른 지표를 표시하는지
- [ ] 전국 검색과 시군구 검색에서 결과 또는 빈 결과 안내가 표시되는지
- [ ] 인터넷 연결 상태에서 배경 타일이 표시되는지, 연결을 끊었을 때 경계 표시와 재시도 안내가 남는지
- [ ] 의미검색 모델을 발표 PC에서 처음 내려받을 수 있는지, 실패·지연 시 규칙 검색으로 전환되는지
- [ ] 발표 직전 사용할 검색어와 지역을 실제 화면에서 한 번씩 확인했는지
