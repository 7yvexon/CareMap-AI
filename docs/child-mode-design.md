# 아동 모드 화면 설계 및 현재 구현

## 상태

이 문서는 현재 아동 모드 동작과 자료 한계를 정리한다. 지도는 0~17세 주민등록인구 비율과 지역아동센터 표준데이터 기록 관측 상태를 별도 지표로 전환해 볼 수 있다. 기록 상태는 시군구 기준이며, 세부 경계를 표시할 때 상위 시군구 상태를 반복해 보여준다. 개별 시설 원자료 행·이름·주소와 주소록 수치는 브라우저 화면에 넣지 않는다.

## 설계 목표

아동 돌봄 시설 기록과 아동 인구를 함께 살펴볼 수 있게 하되, 자료 미관측을 시설 부재나 복지 공백으로 해석하지 않는다. 이용 자격, 실제 수요, 대기, 이용 가능 인원은 공개 데이터로 판정하지 않는다.

화면 상단에 `어르신`과 `아동 돌봄` 모드를 둔다. 모드는 지도 제목, 지표, 범례, 지역 상세 패널을 함께 바꾸며 기존 시도 → 시군구 → 읍면동 선택을 유지한다. 두 모드 지표를 하나의 점수로 합치거나 전국 순위를 만들지 않는다.

## 사용할 자료와 표시 기준

| 자료 | 현재 확인 상태 | 화면에서 허용할 표현 |
| --- | --- | --- |
| 전국지역아동센터 표준데이터 | 2026-11-14 수집본 2,570행. 행별 기준일은 2024-08-08~2026-10-26이다. 2026-10-01 경계에 좌표 2,570행 모두 연결됐다. 주소 접두어·좌표 지역 검토 후보 6행은 5개 시군구 쌍이며 일반 기록 수에서 제외된다. 생성 집계의 일반 기록은 2,564행이다. 256개 시군구 중 146곳에서 일반 기록을 확인했고, 110곳은 이 수집본에서 일반 기록 미관측이다. 고유 시설 중복 여부는 검증되지 않았다. | `좌표 기준 표준데이터 기록 행 수`와 `주소·좌표 검토 제외 행 수`를 별도로 표시한다. 행 수는 고유 시설 수나 현재 운영 시설 수가 아니다. 지도 색상은 기록 수가 아니라 0~17세 주민등록인구 비율을 나타낸다. |
| 국가아동권리보장원 2025년 말 주소록 | 공지 첨부 4,176행. 시설 유형 열은 없고 대표자 이름 열도 없다. 기존 분석은 C 110곳 중 109곳에서 주소록 기록을 연결했으나, 재계산 간 미연결 건수가 달라 교차표 검증이 필요하다. | 교차표가 재현되고 이용 조건을 확인한 뒤에만 `2025년 말 주소록 기록 수`를 별도 지표로 표시한다. 표준데이터와 합쳐 하나의 최신 시설 수로 만들지 않는다. |
| 행정안전부 행정동별 연령별 주민등록 인구 | 2026-10-31 기준. 0~17세 남녀 열 36개가 모두 존재한다. 3,620개 행정동 및 생성된 시군구·시도 집계가 원자료와 일치하며, 전국 합계는 6,498,186명이다. 현재 아동 모드에서 인구 수와 비율로 표시한다. | `0~17세 주민등록인구`와 `전체 인구 중 비율`로 표시한다. 이 수치는 전체 연령 인구 참고값이며 복지 대상 아동·돌봄 수요를 뜻하지 않는다. |

주소록의 2025년 행정구역명과 현재 경계가 다르다. 기존 문서의 주소록 미연결 집계는 46건 미연결·1건 모호이고, 별도 재계산은 50건 미연결·0건 모호로 달랐다. 두 계산 모두 C 지역 110곳 중 109곳에 기록을 연결했지만, 시군구별 주소록 수와 비율은 교차표를 재현하기 전까지 확정하지 않는다. 109곳이라는 결과도 현재 운영 여부를 확인한 수가 아니라 주소록 기록을 지역에 연결한 결과다.

## 화면 구성

### 1. 모드 전환과 필터

- 상단에 `어르신` / `아동 돌봄` 전환 버튼을 둔다.
- 시도, 시군구, 읍면동 필터는 기존 동작을 유지한다.
- 모드를 바꿔도 선택 지역은 유지하고, 해당 지역에 자료가 없으면 값을 0으로 바꾸지 않고 `자료 미관측`으로 표시한다.

### 2. 아동 모드 요약 카드

현재 UI는 출처별 지표를 나란히 보여준다.

- `표준데이터 기록 행 수` — 정상 집계 2,564행; 기준 수집본 2,570행 중 검토 후보 6행 제외, 행별 기준일 상이
- `0~17세 주민등록인구` — 2026-10-31
- `자료 상태` — 선택 지역에서 표준데이터 기록 확인 / 이 수집본에서 미관측
- 주소록은 시군구 교차표와 재사용 조건이 확인되지 않아 현재 표시하지 않음

수집본에서 미관측된 지역은 `0개` 또는 `센터 없음`으로 표시하지 않는다. 주소록 미연결도 시설이 없다는 뜻으로 바꾸지 않는다.

### 3. 지도와 범례

기본 지도 색상은 선택 지역 인구 중 0~17세 주민등록인구 비율을 나타낸다. 별도 `지역아동센터 기록 관측` 보기에서는 표준데이터 행이 관측된 시군구를 초록, 검토 후보만 있는 시군구를 주황, 이 수집본에서 기록 미관측인 시군구를 회색으로 표시한다. 시도 배경지도는 해당 시도의 지역 단위 관측 범위를 요약해 일부 관측과 전체 관측을 다른 색으로 나타낸다. 센터 점과 개별 주소는 표시하지 않는다.

2,570개 원자료 행은 모두 좌표가 경계에 연결됐으며, 주소 접두어·좌표 지역 검토 후보 6행은 정상 시군구 기록 수에서 제외하고 검토 행 수로 표시한다. 남은 2,564행은 좌표 배정 시군구 기록 수다. 이 수는 고유 시설 수나 현재 운영 여부가 아니며, 인구 비율에 합산하지 않는다. 회색은 해당 지역에 시설이 없다는 판정이 아니라 현재 수집본에서 일반 기록이 보이지 않는다는 뜻이다.

`address_coordinate_conflicts.csv`의 6행은 5개 시군구 쌍의 주소 접두어·좌표 지역 차이다. 자동 검토 후보이며 여섯 행 모두의 좌표 오류를 확인했다는 뜻은 아니다. 데이터 상태에서 정상 기록 수와 검토 제외 수를 분리하고 원자료를 다른 지역으로 임의 이동하지 않는다. 146/110은 검토 후보를 제외한 시군구별 정상 기록 관측 상태다. 6행이 걸친 양쪽 시군구는 모두 별도 정상 기록도 있어 이 후보를 재검토해도 146/110은 바뀌지 않지만, 지역별 행 수는 달라질 수 있다.

인구 비율 보기와 센터 기록 관측 보기마다 범례를 따로 보여준다. 센터 보기에서 읍면동 경계의 색은 각 행정동 자체의 센터 수가 아니라 상위 시군구 상태다. 팝업에도 이 집계 단위를 표시한다. 주소록 연결 미확인은 지도 무늬로 표시하지 않으며, 주소록은 현재 화면에 포함하지 않는다.

### 4. 선택 지역 상세 패널

예시 문구:

```text
선택 지역: ○○시 ○○구
표준데이터 기록: 12행 · 좌표 기준, 검토 후보 제외
주소·좌표 검토: 1행
0~17세 주민등록인구: 8,430명 · 2026.10.31
```

표준데이터 기록이 없는 지역은 다음처럼 표시한다.

```text
표준데이터: 이 수집본에서 기록 미관측
이는 해당 지역에 시설이 없거나 이용할 수 없다는 뜻이 아닙니다.
```

주소록 수치는 현재 패널에 표시하지 않는다. 향후 추가할 경우 표준데이터와 별도 지표로 두고 출처, 기준일, 행정구역 연결 상태를 함께 적는다.

### 5. 자료 설명과 한계

아동 모드에 다음 안내를 항상 노출한다.

> 이 화면은 공개자료에서 확인된 시설 기록과 주민등록 인구를 보여줍니다. 자료 미관측은 시설 부재나 복지 공백을 뜻하지 않으며, 0~17세 인구는 지원 자격이나 실제 돌봄 수요가 아닙니다. 운영 여부, 정원, 이용 가능성은 해당 기관에 확인해야 합니다.

정원·현원·종사자 수의 공란 비율은 별도의 데이터 품질 영역에서 출처와 함께 보여줄 수 있다. 공란을 0명, 빈자리, 대기 수요로 바꾸지 않는다.

## 표현 원칙

| 사용 | 피할 표현 |
| --- | --- |
| 이 수집본에서 미관측 | 센터 없음, 서비스 공백 |
| 2025년 말 주소록에서 기록 확인 | 현재 운영 중, 서비스 이용 가능 |
| 0~17세 주민등록인구 | 돌봄 필요 아동, 지원 대상 아동 |
| 표준데이터 기록 행 수 | 확정 시설 수, 이용 가능 시설 수 |
| 자료 연결 미확인 | 해당 지역에 시설이 없음 |

자료가 없는 지역은 순위에서 제외하거나 `자료 미관측` 상태로 따로 보여준다. 부족 순위, 취약지역 레이블, 아동·노인 지표를 합친 점수, 개인별 위험 예측은 만들지 않는다.

## 시연 흐름

1. `아동 돌봄` 모드로 전환한다.
2. 시도와 시군구를 선택해 지도 범위를 좁힌다.
3. 지도 지표를 `0~17세 인구 비율`과 `지역아동센터 기록 관측`으로 각각 바꿔 본다. 센터 보기에서 회색은 이 수집본의 미관측 상태이며 시설 부재 판정이 아님을 설명한다.
4. 선택 지역 패널에서 표준데이터 일반 기록 행 수와 주소·좌표 검토 제외 행 수를 확인한다. 개별 시설 원자료 행은 화면에 제공하지 않는다.
5. 선택 지역의 0~17세 주민등록 인구를 보조 지표로 확인한다.
6. 주소록은 현재 화면에 포함되지 않았으며, 교차표와 재사용 조건 검토가 끝나기 전에는 표준데이터와 결합하지 않는다고 설명한다.
7. 화면의 기록만으로 시설 부재, 이용 자격, 수요, 이용 가능성을 판단하지 않는다고 안내한다.

## 완료된 구현·검증

- 2026-10-31 인구 파일의 0~17세 남녀 36개 열을 합산했다. 전국 합계 6,498,186명이며, 3,620개 행정동 값과 256개 시군구·16개 시도 합계가 원자료와 일치했다.
- 빌드의 `countNumber`는 연령별 숫자 값이 비거나 없거나 음수·정수가 아닌 값·안전 정수 범위 밖이면 실패한다. 따라서 필요한 연령 열이 빠져 값이 누락되면 빌드가 실패하며, 최신 전체 빌드도 통과했다.
- 표준데이터 좌표 2,570행을 2026-10-01 경계에 모두 연결했다. 주소·좌표 검토 후보 6행은 일반 기록 수에서 분리해 2,564행을 집계한다. 이 수집본의 상태는 일반 기록 관측 146개 시군구, 미관측 110개 시군구다.
- 기본 지도는 0~17세 인구 비율을 표시한다. 별도 기록 관측 지도를 제공해 일반 기록 관측, 검토 후보만 있음, 수집본에서 미관측 상태를 시군구 기준으로 표시하며, 읍면동 경계에서는 상위 시군구 상태를 반복한다. 시설 부재 판정이나 주소록 연결 미확인을 나타내지 않는다.
- 개별 센터 행·이름·주소는 브라우저용 생성 자료에 포함하지 않는다. 화면의 센터 수는 표준데이터 기록 행 수이며 고유 시설 수나 현재 운영 수가 아니다.

## 다음 단계

- 주소록 교차표 결과가 기존 계산(46건 미연결·1건 모호)과 재계산(50건 미연결·0건 모호)에서 달랐다. 시군구 분할·통합 규칙과 미연결 행을 재현 가능하게 정리한 뒤 지역별 주소록 수치를 검토한다.
- 국가아동권리보장원 2025년 주소록의 재사용 조건을 확인한다. 교차표와 조건을 확인하기 전까지 주소록 자료는 화면에 표시하지 않는다.
- 표준데이터의 중복 행이 서로 다른 시설인지 중복 등록인지는 아직 검증하지 않았다. 이름·주소·좌표 중복을 검토하고, 고유 시설 수를 주장할 수 있는 식별 규칙을 마련한다. 그전까지는 행 수만 표시한다.
- 주소·좌표 검토 후보 6행 가운데 장수군 공식 목록으로 확인한 1행 외의 5행은 개별 근거로 검증하지 않았다. 주소·좌표를 원자료에서 임의 변경하지 않고 근거를 추가 확인한다.
