# 아동 복지 공백 분석용 데이터 검토

## 검토 결과

전국 지역아동센터 표준데이터는 위치·정원·현원·종사자 정보를 제공해 CareMap의 아동 돌봄 축 후보로 쓸 수 있다. 다만 현재 수집본은 전국 자료라고 단정해 복지 부족 지역을 계산하기에는 지역별 제출 범위와 인원 항목의 누락이 커서, 대시보드에는 아직 연결하지 않았다.

## 출처와 수집 자료

- 공식 출처: [공공데이터포털 전국지역아동센터표준데이터](https://www.data.go.kr/data/15129438/standard.do)
- 원본 수집일: 2026-11-14
- 포털 수정일: 2026-11-13
- 수집 행: 2,570개
- 저장 위치: `data/source/national_child_centers_20261114.json`
- 보존 필드: 센터명(`CNTR_NM`), 시도·시군구(`CTPV_NM`, `SGG_NM`), 도로명·지번 주소, 위도(`LAT`), 경도(`LOT`), 전화번호, 면적, 정원, 현원, 종사자 수, 운영기관 유형, 데이터 기준일, 제공기관 코드·명
- 대표자 이름은 수집본에서 제외했다.

## 스냅샷 대조 절차

저장소에는 2026-11-14 수집본 JSON만 있고 원본 CSV, 내려받기 기록, API 호출 기록 또는 지역아동센터 수집기가 없다. 따라서 저장본이 포털의 전체 CSV 다운로드에서 만들어졌는지 API 페이지 수집에서 만들어졌는지는 확인할 수 없다. 필드 이름이나 JSON 형식만으로 과거 수집 방식을 추정하지 않는다. 다음 갱신에서는 전국 통합 CSV를 직접 내려받는 절차를 기준으로 하고, 원본 파일명·다운로드일·포털 수정일·행 수·SHA-256을 함께 기록한다.

현재 포털 파일은 저장소의 추적 파일과 분리된 `tmp/child-center-current.csv`에 두고 다음 스크립트에 입력해 이전 스냅샷과 비교한다. 이 입력 경로와 결과 디렉터리는 `.gitignore`에 등록되어 있다. `data/source/` 안의 입력·출력은 스크립트가 거부한다. CSV를 대화 첨부 경로 등 저장소 밖에 두고 절대 경로로 전달해도 된다. 이 스크립트는 포털에서 파일을 내려받지 않으며 입력 CSV/JSON과 저장된 원본은 수정하지 않는다.

```sh
node scripts/compare-child-centers.mjs "tmp/child-center-current.csv"
```

### 2026-11-14 현행 포털 자료 대조

- 공공데이터포털 페이지의 수정일은 2026-11-13이다. 2026-11-14에 포털이 내려받기 화면에서 사용하는 표준데이터 JSON 응답을 조회하고, 비교 입력용 UTF-8 CSV로 직렬화했다. 이 파일은 포털이 내려주는 원본 CSV 바이트가 아니라 공식 응답에서 만든 비교용 파일이다.
- 파일명: `child-center-current.csv` (`tmp/` 아래, Git 제외). 행 수: 2,570개, 열 수: 17개. SHA-256: `fb08da65ee7807dca1adf0c5e2c6850c502a1459b9d7e3bbeea36543308d3b63`.
- 저장소 기준 JSON(`national_child_centers_20261114.json`, 2,570개)과 현행 자료의 2,570행을 이름·주소·위경도 정규화 기준으로 모두 짝지었다. 정확 키 매칭 2,570행, 보조 매칭 0행, 미매칭 0행, 모호 매칭 0건이다. 매칭된 행에서 실제 필드 차이는 0건이다.
- 이전 CP949 재구성본에서 `나눔과기쁨지역아동센터`의 `lot_address`는 주소 사이의 NBSP가 `?`로 바뀌었고, `독산1동지역아동센터`의 `road_address`는 한글 도로명이 깨져 보였다. 포털 원 JSON 응답을 확인하니 두 필드 모두 저장본과 같았다. CP949 재구성 중 문자 손상이 만든 오탐이어서 UTF-8 비교본으로 교체했다. 주소나 좌표 원본은 고치지 않았다.
- 따라서 현행 포털 자료를 다시 받아도 관측 지역은 146곳, 이 수집본에서 센터 기록 미관측 지역은 110곳으로 같으며, C 감소는 0곳이다.

기본 출력은 `tmp/child-center-comparison/`에 생성된다. `summary.json`에는 양쪽 파일의 행 수와 SHA-256, 시군구 커버리지 변화, C 감소 수와 매칭 규칙이 기록된다. `matched_record_changes.csv`는 매칭된 행에서 이름·주소·좌표 등이 달라진 경우를 보여 준다. 동일한 이름·주소·좌표가 중복된 행은 각 파일의 중복 개수를 기준으로 짝짓는다. 대표자명 필드는 매칭에 쓰지 않고 어떤 보고서에도 기록하지 않는다.

- CSV는 UTF-8(BOM 포함 가능), UTF-16 또는 `euc-kr`/CP949 계열을 읽는다. 필드는 열 위치가 아닌 헤더명으로 연결한다. 위도는 `LAT`/`위도`, 경도는 `LOT`/`경도`다.
- 센터명은 Unicode NFKC와 소문자 정규화 후 공백·문장부호·기호를 제거한다. `지역아동센터` 접미어는 보존한다.
- 주소는 Unicode NFKC와 소문자 정규화 후 공백·쉼표·가운뎃점·괄호를 제거한다. 여러 하이픈 표기는 `-`로 통일하며 번지 구분에 쓰이는 하이픈과 슬래시는 보존한다.
- 1차 매칭은 센터명+정규화 주소, 2차는 센터명+위경도 소수점 다섯 자리 반올림이다. 유일하게 대응되는 행만 자동 매칭한다. 같은 주소·좌표나 같은 이름과 시군구로 추정되는 변경 쌍은 수동 검토 목록에 둔다.

CSV 보고서에는 확정 매칭되지 않은 행, 변경 가능성이 있어 수동 확인할 행, 좌표 결합 문제, 주소의 시도·시군구 접두어와 좌표 결합 지역이 다른 행, 시군구별 커버리지가 담긴다. 미매칭 행은 이름·주소·좌표의 변경일 수 있으므로 신규 개소나 폐쇄로 단정하지 않는다.

시군구 커버리지는 저장소의 2026-10-01 행정동 경계에 좌표를 결합해 계산한다. 주소의 시도·시군구 접두어가 좌표 결합 지역과 다르면 검토 대상으로 내보내며, 이는 불일치 후보이지 자동 판정이나 원본 수정이 아니다.

공식 표준데이터의 영문 필드 코드에서 `LAT`는 위도, `LOT`는 경도다. 코드명이 일반적인 `LON`이 아니므로 원본을 확인할 때 경도 필드가 빠진 것으로 오해하지 않도록 한다.

포털은 데이터 목록에 제공기관 123곳을 표시한다. 수집본에서 기록이 확인된 시도는 현행 16개 중 15개이며 세종은 관측되지 않았다. 이는 세종에 센터가 없다는 뜻이 아니라 해당 수집본에서 자료를 확인하지 못했다는 뜻이다.

수집 JSON에는 서로 다른 제공기관 코드·명 조합이 124개 있다. 검토용 커버리지 CSV에서는 칠곡군의 제공기관명 두 개(`경상북도 칠곡군`, `경상북도 칠곡군 주민생활지원과`)를 한 지역의 세미콜론 구분 값으로 묶어 고유 제공기관 문자열이 123개가 된다. 따라서 123 대 124는 그 자체로 한 제공기관 자료가 누락됐다는 증거가 아니다. 포털의 제공기관 목록 수도 256개 시군구 각각의 시설 유무를 독립적으로 확인해 주지는 않는다. 이 원본만으로는 “제공기관 자료 확인 못함”을 판정할 수 없으므로, 커버리지 CSV의 미관측 지역은 “이 수집본에서 센터 기록 미관측”으로 해석해야 한다. B와 C를 나누려면 별도의 시군구별 제공자료 목록이 필요하다.

## 품질과 지역 결합

개별 행의 데이터 기준일은 2024-08-08부터 2026-10-26까지 분산되어 있다. 2,570개 행 모두 `LAT`와 `LOT` 값이 있으며 좌표 범위도 유효했다. 좌표를 2026-10-01 행정동 경계에 재결합한 결과 2,570개 모두 정확히 하나의 경계 안에 들어갔다. 이전 기록의 2,569개 결합·1개 미결합 집계는 재현되지 않아 정정한다.

다만 좌표와 원자료 주소가 충돌하는 행이 1개 확인됐다. 원자료는 한우리지역아동센터를 전북특별자치도 장수군 장계면 성곡길 4-3으로 표시하지만, 좌표 결합 결과는 경상남도 함양군이다. [장수군청의 지역아동센터 현황](https://www.jangsu.go.kr/index.jangsu?menuCd=DOM_000000106007004004)에도 해당 센터와 주소가 장수군 시설로 기재돼 있다. 지도 위치나 시군구 집계에서는 이 행을 좌표만으로 확정하지 말고 주소와 대조해 검토 대상으로 표시해야 한다. 전북특별자치도 제공기관의 287행은 좌표상 전북 15개 시군구를 모두 포함하지만, 이 불일치 1행 때문에 경남 함양군에도 배정된다. 검토용 커버리지 CSV의 146개 관측 시군구·110개 미관측 시군구 합계는 이 한 행을 장수군으로 바로잡아도 변하지 않지만, 두 지역의 행 수는 각각 1건씩 달라진다. 관측되지 않은 시군구는 시설이 없거나 복지 수요가 크다고 판정할 수 없다.

인원 항목 공란은 정원 607건(23.6%), 현원 834건(32.5%), 종사자 수 822건(32.0%)이다. 특히 현원과 정원 자료만으로 이용 가능 인원이나 대기 규모를 추정하지 않는다.

원자료 시군구명은 일부가 상위 시 전체 이름으로 기록되어 현행 행정구역명과 직접 결합되지 않는다. 수집본 557건은 원자료 시군구명과 좌표가 들어가는 2026년 경계의 시군구명이 달랐다. 지역별 계산을 한다면 행정동 코드에 연결된 지도 경계를 기준으로 좌표를 결합하고, 주소명만으로 지역을 나누지 않아야 한다.

- 2026-10-01 경계에 맞춰 시도·시군구 필드와 시설 소재지의 행정구역 문자열을 대조했다. 기존 C 110곳 중 103곳은 시군구 또는 주소에서 현재 지역을 직접 확인했다. 세종 1곳은 행정구역명 변경을 연결하고, 화성시의 4개 신설 구와 인천 검단구는 주소의 읍·면·동 이름을 이용한 보조 연결로 5곳을 추가했다. 그 결과 109곳에서 2025년 말 주소록의 시설 기록이 연결됐고, 인천 영종구 1곳은 개별 시설 주소를 연결하지 못했다.
- 영종구는 현행 행정구역 개편 전의 인천 중구 자료와 비교해야 한다. 주소록의 중구 3개 행은 송월동·전동·연안동 쪽 주소여서 영종구로 배정하지 않았다. 이 결과는 “2025년 주소록에서 영종구 시설을 확인하지 못함”을 뜻하며, 현재 시설이 없다는 판정은 아니다.
- 주소록의 시군구 이름은 현행 기준보다 오래됐고 좌표도 없다. 주소 문자열을 활용한 5개 보조 연결은 행정동 코드·좌표 기반 결합이 아니므로 시연 지도에 반영하기 전 추가 검증이 필요하다. 미연결·모호 행이 남아 있으므로 109곳은 주소록에서 지역을 연결한 하한으로 해석한다.
- 이 주소록은 표준데이터에 새로 빠진 행을 보완하는 별도 원천이다. 두 자료의 기준 시점과 지역 분류를 함께 합쳐 하나의 최신 시설 수로 표시하지 않는다. 화면에서는 표준데이터의 관측 상태와 2025년 주소록 확인 여부를 출처·기준일이 있는 별도 상태로 보여 준다.

## 서비스 수요와의 비교 원칙

CareMap에 이미 포함된 행정동별 주민등록 연령 자료에서 0~17세 인구를 집계해 볼 수 있다. 하지만 아동 전체 인구는 복지지원 대상 아동이나 실제 돌봄 수요를 뜻하지 않는다. 장래에 시각화한다면 우선 “지역아동센터 수 / 아동인구 1만 명” 같은 관측 지표로 표시하고, 지역별 데이터 제출 여부와 센터별 정원 기재율을 함께 보여야 한다. 자료가 없는 지역을 0개로 계산하거나 이를 복지 공백으로 이름 붙여서는 안 된다.

현재 권장 상태는 표준데이터를 2026년 관측 자료로, 국가아동권리보장원 주소록을 2025년 말 보완 자료로 분리해 보여 주는 것이다. 지도에서 110곳을 시설 0개나 복지 공백으로 색칠하지 말고, 2025년 주소록에서 시설 기록을 연결한 109곳에는 출처와 기준일을 표시한다. 자료 미관측·행정구역 연결 미확정은 시설 부재나 복지 수요로 해석하지 않는다.
