# 2026 사회보장 AI 경진대회 제안서 근거 정리

검토일: 2026-11-14

용도: 최신 지정 양식에 옮기기 전 내부 작성 기준. 이 문서는 제출 양식이 아니며, 양식의 분량·필수 항목을 대신하지 않는다.

## 제안의 중심

**CareMap은 복지 공백을 판정하거나 지원 자격을 예측하는 AI가 아니라, 전국 공개자료의 범위와 기준일을 드러내며 사용자가 지역별 사회서비스 후보를 찾아보도록 돕는 시제품이다.**

문제 정의는 “공공 서비스 정보가 지역과 자료별로 나뉘어 있어 주민과 현장 담당자가 후보를 찾고 확인하는 데 번거로움이 있다”는 가설로 제시한다. 현장 인터뷰나 사용자 연구는 아직 확인되지 않았으므로, 이를 검증된 사용자 조사 결과처럼 쓰지 않는다.

## 시연 순서 초안

1. 전국 지도에서 시도와 시군구를 선택하고, 인구·서비스 기록·시설 통계의 단위와 기준일을 확인한다.
2. “혼자 지내며 반찬을 받기 어렵다”와 같은 합성 문장을 입력한다. 개인 상담 내용이나 식별정보는 사용하지 않는다.
3. 의미검색 토글을 켜고 첫 제출을 한다. 유사 중분류 후보를 보여주면 사용자가 맞는 유형을 선택하고 버튼을 다시 누른다. 선택된 의미 유형만 추가되며 규칙 분류와 입력어 검색도 계속 함께 실행된다고 설명한다.
4. 후보 카드에서 프로그램명·분류·제공기관 등 원자료에서 온 필드와 데이터셋 출처 페이지를 확인한다. 출처 링크는 개별 행이 아니라 데이터셋 페이지를 연다. 결과는 연락·운영 확인이 필요한 탐색 후보임을 말한다.
5. 자료가 없는 지역도 서비스 부재로 판정하지 않으며, 앱이 수요나 지원 자격을 예측하지 않는다고 마무리한다.

지도는 서비스 기관 주소 핀이 아니라 행정구역 경계와 집계를 보여준다. 읍면동을 선택해도 서비스 후보 검색은 상위 시군구 범위다. 의미검색은 첫 실행에 외부 모델 다운로드가 필요하므로, 발표 장비에서는 전날 같은 브라우저에서 모델을 미리 캐시하고 인터넷 연결이 끊긴 경우 규칙 기반 검색으로 바꾸되 로컬 CareMap 서버는 계속 켜 둔다. 실제 캐시 동작·기기 성능은 리허설에서 확인해야 한다.

## 예상 질의응답 초안

**Q. 이 지도가 복지 사각지대나 필요한 사람을 찾아주나요?**

A. 아닙니다. 현재 데이터에는 개인별 신청·대기·미충족 요청·이용 결과가 없어 사각지대나 지원 자격을 판정할 수 없습니다. 공개자료에서 확인되는 지역 현황과 서비스 후보를 탐색하도록 돕습니다.

**Q. 90,081행이면 기관 90,081곳이 있다는 뜻인가요?**

A. 아닙니다. 프로그램·자원 기록 행이며 한 기관이 여러 행에 있을 수 있습니다. 현재 화면은 이를 고유 기관 수나 이용 가능 수용력으로 표현하지 않습니다.

**Q. AI가 실제로 더 정확한가요?**

A. 아직 비교 평가를 하지 않았습니다. 일반 임베딩 모델이 서비스 유형 후보를 보여주고 사용자가 선택합니다. 현장 질의로 규칙 기준선과 유형 적합도, 원자료 근거 일치율, 탐색 시간과 지연을 비교할 계획입니다.

**Q. AI에 입력한 문장은 어디로 가나요?**

A. 유형 임베딩은 브라우저에서 계산하고 외부 생성형 AI 추론 API에는 보내지 않습니다. 선택한 지역·유형과 검색어는 CareMap의 로컬 서비스 검색 API에 전달됩니다. 개인식별정보는 입력하지 않도록 안내합니다.

**Q. 자료가 없는 지역은 서비스가 없다고 보면 되나요?**

A. 아닙니다. 이 수집본에서 기록을 찾지 못했다는 뜻일 뿐입니다. 제공기관 목록, 자료 제출 범위와 기준일이 다르므로 서비스 부재로 해석하지 않습니다.

**Q. 현장에서 어떻게 운영할 계획인가요?**

A. 현재는 검색 후보 탐색 시제품입니다. 다음 단계는 담당자와 합성 질의를 검토하고, 공식 원자료의 갱신 기준과 기관에 실제 운영 여부를 확인하는 절차를 정하는 것입니다. 협약이나 실제 의뢰 연계는 아직 완료되지 않았습니다.

## 실행 확인 결과 (2026-11-14)

- 분리된 로컬 서버에서 `/api/health`가 HTTP 200과 `ready: true`를 반환했다. 자원 90,081행, 행정경계 3,559개, 예상·색인 시도 16개, 누락·예상 밖 시도 0개로 보고했고 페이지 자료·검색·경계 검사 세 항목이 모두 참이었다.
- 격리된 headless Chrome에서 `/`와 `data/national_data.js`가 로드됐다. 지도 DOM과 Leaflet 타일 12개, 경계 경로 16개가 렌더링됐고 자료 상태는 `자료 준비됨`이었다.
- 합성 질의 `혼자 지내며 반찬을 챙기기 어려워요`로 브라우저 모델을 실제 실행했다. `식사지원`과 `일상생활지원`이 각각 0.859, `가사지원`이 0.850으로 후보에 표시됐다. `식사지원`을 선택해 다시 검색하자 API가 8개 후보를 반환했고 검색 방식은 `사용자 선택 의미 유형과 규칙·키워드 후보 검색`으로 표시됐다.
- 이 확인은 단일 합성 질의와 단일 headless 환경에서 로딩·흐름을 확인한 것이다. 모델 정확도, 현장 적합도, 첫 로드 시간, 캐시 재사용, 오프라인 동작, 발표용 장비의 지도를 검증하지 않았다. 임베딩 후보 중 두 유형 점수가 같았으므로 현장 질의 평가 없이 추천 정확도를 주장하지 않는다.
- 임시 브라우저 프로필은 Chrome 자식 프로세스가 종료된 뒤 정리했다. 검증 스크립트는 `tmp/`에서 제거했으며 저장소에는 포함하지 않았다.

## 제출 전 증거 보완 우선순위

1. 발표에 사용할 노트북·브라우저에서 지도 표시, 지역 필터, 검색 결과, 의미검색 첫 다운로드와 캐시 후 동작을 직접 리허설하고 화면 캡처를 남긴다.
